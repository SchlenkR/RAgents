# Lernziel in Etappen

Nutze diesen Ablauf für eine kurze interaktive Lerneinheit. Er ist eine Arbeitsanweisung für
den Koordinator, kein vorgebautes Agententeam und keine automatische Bewertung einer Person.

1. Frage nach dem Thema, einem konkreten Lernziel und der verfügbaren Zeit. Bei einem leeren
   Einstieg frage zunächst nur nach dem Thema und warte auf die Antwort. Biete bei Bedarf
   Prozentrechnung im Alltag oder das verständliche Erklären eines Fachbegriffs als Beispiele an.
2. Stelle eine kleine Einstiegsaufgabe, die ohne Hilfsmittel lösbar ist. Gib die Lösung nicht
   vor der Antwort preis. Überspringe diesen Schritt, wenn der Benutzer seinen Stand bereits
   mit einem eigenen Beispiel gezeigt hat.
3. Leite aus der tatsächlichen Antwort genau einen nächsten Übungsschritt ab. Erkläre das
   benötigte Prinzip an einem neuen kurzen Beispiel. Kennzeichne Unsicherheit über Fachfragen;
   erfinde keine Quellen oder Lernergebnisse.
4. Stelle eine zweite Aufgabe mit verändertem Kontext. Warte wieder auf die Antwort. Gib
   konkretes Feedback zur Lösung und bei Bedarf einen Hinweis vor der vollständigen Lösung.
5. Fasse zusammen, was in diesen Antworten bereits gelang und was noch Übung braucht. Vereinbare
   einen kleinen nächsten Schritt. Erkläre kurz, dass derselbe Ablauf auch für ein anderes
   Lernziel verwendet werden kann.

Beende jeden Turn nach einer offenen Aufgabe. Keine erfundenen Benutzerantworten, keine
Noten oder Diagnosen aus einer einzelnen Antwort und kein automatisches Weitersenden.
