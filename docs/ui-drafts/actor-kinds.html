Chatblase und Gespräch

LLM-Karten behalten den runden Kopf und ihre Nachrichtenvorschau. Sie zeigen, was ein Gesprächspartner gerade bearbeitet.

Abgeschrägtes Modul mit TS

Ein flacher Umriss und die kleine Sprachkennung unterscheiden Script-Actors von Gesprächskarten. Der Handle wählt die Karte aus, ohne einen großen LLM-Symbolblock.

Quelltext direkt öffnen

Der Skript-Knopf zeigt den Code in einem Dialog unterhalb der Kopfzeile. Status und Anzahl zugestellter Eingaben bleiben auf der Karte; der schmale Statusbalken zeigt die laufende Arbeit.

Die Scriptform ist in der App umgesetzt. Diese HTML-Seite bleibt eine interaktive Gestaltungsansicht mit Beispielinhalt. Die nebenliegenden Bilder zeigen die echten Komponenten in einer neutralen Browser-Testansicht, keinen echten Run.

Skript von @route

TypeScript
// Vereinfachte Regel zur Erklärung der Darstellung.
function route(answer: string) {
  return {
    recipient: "@reviewer",
    text: answer,
  };
}
