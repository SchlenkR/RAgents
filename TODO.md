## Ideas

- Subscription with condition (01.10.2026): `event_subscribe` and `ragents.watch` overlap in purpose but not in mechanism (lossless events versus a derived state with a clock and a free condition). One family would add optional `condition`, `quietSeconds`, and `instruction` to the subscription and absorb `watch_*`; the baseline would be rebuilt by replay and the `observe` operation dropped. Medium effort in the engine; an external run script depends on the watch today.
- Compaction plugin (27.09.2026): mask older tool results in the model context and fetch them back from the journal when needed. Starting points are `context.compacted` and the place in `AgentTurn` where the hooks' notes are attached to the projection today (`drivers/agent-turn.ts`); the projection itself stays pure.
- Show an actor's model context in the UI (27.09.2026): the projection is now readable from the journal; a tab could show what the model actually sees, including compactions.

- Let detached processes only arise via a starter of the executor that remembers them, so that the process bar and stop on a Mac also reach programs from `/bin` and `/usr/bin` (boundary in `docs/spec/plugins.md`, 23.09.2026).

- Folder per run also on the workstation, created there by the executor (for example a worktree of the opened repository), so that flows that change the repository can run there with the developer's credentials; today such templates fix the folder per run on the server (23.09.2026).

- From the comparison with Hermes Agent 0.21 (Pantheon, 31.08.2026): make the cost per commissioned helper visible in the result of `agent_spawn` and `actor_input` (today only `pnpm driver usage` per actor), and an optional schema check for the answer of an LLM helper, so that a coordinator can demand structured results; TypeScript actors already have that, LLM actors do not.


- Opening a run from the VS Code extension in the browser needs a deep link `?run=`, because the web app does not carry a run in the address; the command `ragents.openRunInBrowser` without callers was removed on 24.09.2026.

- Logo: twelve finished prompts for the psycho character under docs/logo-drafts/drafts/psycho-character/error.md (gitignored) are waiting for a strictly serial Higgsfield run (starter plan: at most four jobs at the same time).

- Fork and ad hoc question tool. We now already have our global chat here, this global coordinator. And we could do that as well. We could make some kind of quick ask thing. Also up in the bar, like a button. There I could just ask a question. And when the answer comes, it could just be shown as a toast or something somewhere. We have to see exactly how, but that's how I imagine it.


- Context compression: here we have to look at what already exists. For example, in terms of ideas. We can of course implement it ourselves, or we use an open source tool for it. There is Headroom maybe, that is pretty cool. But we have to see; in general we need it, of course. And of course we don't want to compress the context completely, but also, let's say, still make it accessible in case it is needed again. That is actually the modern idea. With this feature we also have to look at what the modern idea is for how we compress context.

- validateConfigFileSections checks keys of inactive plugins only with a log hint instead of hard - decide whether this should also become a hard error.

- Schedule triggers following the trigger principle: time as a subscribable event that creates an ActorInput - NOT as waiting/timer in the script (the turn model never waits).
